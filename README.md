# Čeština 2.0 — web

**Veřejné** repo s podstránkami a sub-projekty kolem slovníku cestina20.cz (samotný slovník běží na WordPressu mimo tento repo). Sem patří věci určené na ostrý web: přihlášení k newsletteru, plánovaný Pražský literární kvíz, landing přednášek.

- **Doména:** [cestina20.cz](https://cestina20.cz) — podstránky jdou přes GitHub Pages.
- **Stack:** plain HTML/CSS/JS, multi-projekt layout (každá pod-složka má vlastní `index.html` + `assets/`).

⚠ **Pozor:** repo je veřejné a jede přes GitHub Pages — cokoliv, co není v `_config.yml` v `exclude:`, se publikuje. Rozdělané věci proto držet v exclude listu, dokud nejsou hotové.
